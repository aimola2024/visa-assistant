# Визовый ассистент

Страница для сотрудников визового центра: требования по странам для подачи в Тбилиси и Ереване,
сопроводительные письма, маршруты, чек-листы и ответы клиентам.

## Файлы

- `index.html` — страница
- `data.js` — база требований: где подавать, сборы, документы. Правьте её, когда что-то меняется
- `netlify/functions/generate.mjs` — серверная функция для текстов (держит ключ API)
- `netlify.toml` — настройки Netlify

## Переменные окружения в Netlify

- `ANTHROPIC_API_KEY` — ключ Claude API
- `ACCESS_CODE` — код для сотрудников
- `CLAUDE_MODEL` — необязательно
